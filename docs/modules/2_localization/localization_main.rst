定位
======
定位是机器人借助全球导航卫星系统（GNSS）等传感器获知其位置与朝向的能力。在定位中，卡尔曼滤波、直方图滤波和粒子滤波等贝叶斯滤波被广泛使用[31]。图2展示了使用直方图滤波和粒子滤波的定位仿真。
